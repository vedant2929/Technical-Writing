# Google Docs Documentation

## 1. Introduction
Google Docs is a cloud-based document editor used to create, edit, format, and collaborate on documents.

## 2. Main Features
- Real-time multi-user collaboration.
- Text formatting and styles.
- Headings, tables, images, drawings, links, and equations.
- Comments and suggestions.
- Version history.
- Import and export of documents.

## 3. Creating a Document
1. Open Google Docs.
2. Create a blank document.
3. Enter the document title.
4. Add and format content.
5. Save changes through the online service.

## 4. Formatting
Google Docs supports:
- Font type and size.
- Bold, italic, and underline.
- Text alignment.
- Headings and paragraph styles.
- Bulleted and numbered lists.
- Tables and images.

## 5. Collaboration and Sharing
1. Select the Share option.
2. Invite collaborators using their email addresses or a sharing link.
3. Set permissions:
   - Viewer
   - Commenter
   - Editor
4. Collaborate on the same document.

## 6. Comments and Suggestions
Comments can be added to request feedback or discuss document content. Suggesting mode allows proposed edits to be reviewed before they are accepted.

## 7. Version History
Version history allows users to:
- View earlier versions.
- Identify changes.
- Restore a previous version.

## 8. Import and Export
Google Docs supports formats including:
- DOCX
- PDF
- ODT
- RTF
- HTML
- TXT

## 9. Practical Activity
1. Create a Google document.
2. Share it with a classmate.
3. Try headings, comments, and suggestions.
4. Add a table and an image.
5. Review version history.
6. Restore an earlier version.

## Conclusion
Google Docs supports cloud-based document creation, collaboration, editing, sharing, and version management.
